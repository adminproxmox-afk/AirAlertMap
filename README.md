# AirAlertMap

Учебное приложение для Windows на C++Builder и ассемблере x86. Показывает воздушные тревоги Украины на интерактивной карте. Карта, история и настройки работают в одном окне через локальный интерфейс HTML/CSS/JavaScript в WebView2.

## Карта

UkraineAlarm / Stfalcon предоставляет статусы областей, районов и громад. Программа связывает их с границами по проверенным `regionId`, сохраняет иерархию и показывает тревогу только на затронутой территории. Тревога всей области или района распространяется на подчинённые громады.

- Красный — активная воздушная тревога; при наличии уровня API — Red.
- Жёлтый — уровень Yellow, полученный от API.
- Штриховка — тревога в части территории, а не отдельный уровень угрозы.
- Зелёный — нет активной воздушной тревоги, серый — нет подтверждённых данных.

Если API не передал уровень, активная тревога остаётся красной с подписью «рівень не вказано API». Частичная тревога области не окрашивает все её громады жёлтым. Для `alerts.in.ua` доступна детализация по областям.

Колёсико меняет масштаб, перетаскивание перемещает карту без выделения текста. При приближении появляются границы районов и громад; детализацию можно выбрать вручную. Территорию можно выбрать на карте или в списке. Клавиши `+`, `−`, стрелки и `0` управляют картой.

## Данные и история

HTTPS-запросы и обработка статусов выполняются в C++ в отдельном потоке. Модуль x86 ASM считает области с активной тревогой. Обновление — раз в минуту с учётом ограничений API. При ошибке или отсутствии подтверждения более 90 секунд статусы становятся неизвестными. Справочник сохраняется на 24 часа, выбранная область восстанавливается после запуска.

Python обрабатывает локальную историю наблюдений. Вкладка «Історія» показывает длительности и позволяет экспортировать CSV, JSON или HTML. Перерывы наблюдения учитываются как отсутствие данных. Это не официальный архив. История хранится в `%LOCALAPPDATA%\AirAlertMap`, API-ключ в неё не записывается. Деморежим использует вымышленные состояния и не добавляет их в историю.

## Запуск

1. Запустите `start.cmd` или `build\AirAlertMap.exe`.
2. Откройте «Налаштування», выберите сервис, выдавший ключ, введите ключ и нажмите «Застосувати».
3. При включённом сохранении ключ хранится в защищённом хранилище Windows и загружается автоматически.

Ключи UkraineAlarm / Stfalcon и alerts.in.ua не взаимозаменяемы. Поддерживаются переменные `UKRAINEALARM_API_KEY` и `ALERTS_IN_UA_TOKEN`. Нужен Microsoft Edge WebView2 Runtime; для истории — Python 3.10+. При переносе копируйте всю папку `build` вместе с `web`, `analytics`, `data` и `WebView2Loader.dll`.

## Сборка

Требуются C++Builder Win32 Classic и Turbo Assembler. Откройте `AirAlertMap.cbproj` и нажмите F9 или выполните:

```powershell
.\build.ps1
.\tools\test-extras.ps1
```

Готовая геометрия включена в проект. Для её повторного получения и генерации нужен Node.js:

```powershell
.\tools\prepare-geodata.ps1
```

## Границы территорий

Карта использует OCHA Ukraine COD-AB v05 от Kartographia / OCHA, CC BY 3.0 IGO: 27 регионов, 139 районов и 1769 территорий уровня ADM3. Проверено соответствие всем 122 районам и всем 1455 громадам текущего справочника UkraineAlarm и отдельным городским записям Харькова и Запорожья. Для территорий, отсутствующих в API, показывается общий статус области либо пояснение об отсутствии отдельного статуса.

Источники, лицензии и ограничения геометрии: [data/NOTICE.md](data/NOTICE.md).
