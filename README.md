# AirAlertMap — карта воздушных тревог Украины

Первая рабочая версия Windows-приложения на **C++Builder VCL + x86 assembler**, платформа **Win32**.
Интерфейс на украинском языке. Проект создан в `E:\app\AirAlertMap`.

**Это демонстрационная версия. Актуальные тревоги из интернета пока не загружаются.**
Демонстрационные статусы вымышлены. Для решений о безопасности используйте официальные оповещения.

## Запуск

Откройте `start.cmd` или `build\AirAlertMap.exe`.

В C++Builder откройте `AirAlertMap.cbproj`, выберите **Win32** и нажмите **F9**.
Используется классический компилятор `bcc32.exe` и Turbo Assembler `tasm32.exe`.
Переход на Win64 потребует переписывания ассемблерного модуля под x64 и другой ABI.

Сборка из PowerShell:

```powershell
Set-Location E:\app\AirAlertMap
.\build.ps1
```

Скрипт использует установленный RAD Studio 37.0 или каталог из переменной `BDS`.
Для другой установки передайте `-BdsRoot 'C:\путь\к\Studio\версия'`.
Node.js нужен только при повторной генерации геометрии: `node tools/generate-map.js`.
Приложение собирается со статической VCL/RTL и не требует интернета для демонстрации.

## Что работает

- Географическая карта всех 27 административных единиц Украины, включая АР Крым, Киев и Севастополь.
- Три независимых статуса: тревога, без тревоги, нет данных.
- Выбор области мышью на карте и в выпадающем списке; подсказки при наведении.
- Подсветка выбранного региона и карточка его состояния.
- Ручное переключение демостатуса по циклу: нет данных → без тревоги → тревога → нет данных.
- Возврат к исходному демосценарию: 6 тревог, 18 без тревоги, 3 без данных.
- Кнопка перевода всех регионов в «нет данных».
- Автоматическое вписывание карты при изменении размеров окна, управление кнопками через Tab/Enter.
- Счётчик тревог вызывает настоящий x86-код из `asm\AlertAsm.asm`.

## Структура

| Файл | Назначение |
| --- | --- |
| `AirAlertMap.cbproj` | Проект C++Builder, C++ и ASM в одной сборке |
| `src\AirAlertMap.cpp` | Точка входа приложения |
| `src\MainForm.cpp/.h/.dfm` | Окно VCL, карта, выбор региона, кнопки |
| `src\AlertModel.cpp/.h` | Состояния областей и демосценарий |
| `asm\AlertAsm.asm` | Подсчёт активных тревог, соглашение cdecl |
| `src\MapData.cpp/.h` | Геометрия карты и украинские подписи |
| `data\` | Исходный GeoJSON, метаданные, лицензия геоданных |
| `tools\generate-map.js` | Воспроизводимая генерация MapData.cpp |
| `tests\ModelTests.cpp` | Проверки модели и реального ASM |
| `build.ps1` | Сборка тестов и приложения |

## Проверка

```powershell
.\build.ps1 -TestsOnly
```

14 проверок: длина массива, пустые и некорректные аргументы, большой массив,
отдельный учёт неизвестных статусов, цикл смены состояния, границы индексов и сброс демосценария.
Это тесты настоящего объектного файла ассемблера, без подмены реализацией на C++.

## Следующий этап: актуальные данные

Нужен выбор поставщика API и, если он требует авторизации, его ключ доступа.
Следует добавить отдельный сетевой модуль с HTTPS, разбором ответа и явным сопоставлением идентификаторов
всех 27 регионов. Запросы должны выполняться вне UI-потока, с ограничением времени и учётом лимитов API.
При ошибке сети или устаревших данных нельзя отображать «без тревоги»: нужен статус «нет данных»
или явная пометка об устаревании с временем последнего успешного ответа.
Ключи не хранить в исходниках и не записывать в журнал.

Лицензия и источник географии: `data\NOTICE.md`.
