# AirAlertMap

Учебное приложение для Windows, которое отображает воздушные тревоги на карте Украины. Написано на C++Builder VCL с использованием ассемблера x86.

## Возможности

- Карта 27 регионов Украины с выбором области и просмотром её состояния.
- Отображение тревог, частичных тревог и предварительных угроз.
- Красный цвет — тревога во всей области, жёлтый — частичная тревога или предварительная угроза, зелёный — без активной тревоги, серый — нет данных.
- Автоматическое обновление данных раз в минуту.
- Время последнего успешного обновления и статус подключения.
- Деморежим для работы без интернета и проверки интерфейса.
- Сохранение выбранной области и справочника регионов для более быстрого повторного запуска.
- Интерактивная карта с масштабированием, перемещением и слоями подписей, границ и статусов.
- Локальная история наблюдений и отчёты на Python в HTML, CSV и JSON.

## Как работает

Приложение получает статусы через HTTPS из выбранного API — [UkraineAlarm / Stfalcon](https://api.ukrainealarm.com/) или [alerts.in.ua](https://devs.alerts.in.ua/) и отображает их на карте. Запросы выполняются в отдельном потоке, поэтому интерфейс остаётся доступным во время загрузки.

Интерфейс, сетевые запросы и обработка данных реализованы на C++. Модуль на ассемблере подсчитывает количество регионов с активной тревогой или угрозой.

При ошибке подключения или отсутствии подтверждённого ответа более 90 секунд регионы переходят в состояние «нет данных». Демонстрационные статусы используются только в отдельном деморежиме.

Справочник UkraineAlarm сохраняется на 24 часа. При повторном запуске программа может сразу запросить статусы, учитывая оставшуюся паузу API. Выбранная область восстанавливается автоматически.

Кнопка **«Інтерактивна мапа»** открывает встроенную HTML/CSS/JavaScript-карту. Колёсико изменяет масштаб, перетягивание перемещает карту. Выбор области синхронизируется с главным окном. Карта использует локальные границы 27 регионов.

Кнопка **«Історія та статистика»** запускает локальный анализ на Python и открывает отчёт. История накапливается во время работы приложения; перерывы наблюдения учитываются как отсутствие данных. Это не официальный архив тревог. Файлы хранятся в `%LOCALAPPDATA%\AirAlertMap`, отчёты — в подпапке `reports`. API-ключ в историю и веб-карту не передаётся.

## Запуск

1. Запустите `start.cmd` или собранный файл `build\AirAlertMap.exe`.
2. Нажмите **«Налаштувати API-токен»**, выберите сервис, выдавший ключ, и введите его. Для ключа Stfalcon выберите **UkraineAlarm / Stfalcon**.
3. Оставьте включённым **«Актуальні дані (API)»** для загрузки статусов. Снимите флажок, чтобы перейти в деморежим.

Ключи этих сервисов не взаимозаменяемы. По умолчанию ключ и выбранный API сохраняются в защищённом хранилище учётных данных Windows и автоматически загружаются при запуске. Чтобы использовать ключ только в текущем сеансе, снимите флажок сохранения и примените настройки. Также поддерживаются переменные окружения `UKRAINEALARM_API_KEY` и `ALERTS_IN_UA_TOKEN`.

Для интерактивной карты нужен Microsoft Edge WebView2 Runtime. Для отчётов — Python 3.10 или новее, доступный командой `python`. Основная VCL-карта работает без Python. При переносе сборки копируйте всю папку `build`, включая `web`, `analytics`, `data` и `WebView2Loader.dll`.

## Сборка

Требуется C++Builder / RAD Studio с компилятором Win32 Classic и Turbo Assembler.

Откройте `AirAlertMap.cbproj`, выберите платформу **Win32** и нажмите **F9**. Для сборки из PowerShell:

```powershell
.\build.ps1
```

Для запуска проверок без сборки интерфейса:

```powershell
.\build.ps1 -TestsOnly
```

Проверки аналитики и управления веб-картой:

```powershell
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/map-model.test.js
```

Полная проверка дополнительных модулей, включая запуск Python из C++ без `PATH`:

```powershell
.\tools\test-extras.ps1
```

При первой сборке загрузчик WebView2 берётся из официального NuGet-пакета Microsoft с проверкой SHA-256. Готовые файлы карты уже включены в проект; Node.js нужен только для изменения генератора или проверки JavaScript.
