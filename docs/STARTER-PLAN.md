# План первой версии

Запрос: создать проект в E:\app, карта тревог на C++Builder с ассемблерной частью.

Выбранная основа: Windows, VCL, Win32 Classic, внешний модуль TASM с ABI cdecl.
В окружении обнаружены RAD Studio 37.0, bcc32.exe и tasm32.exe.
VCL соответствует установленной IDE; Win32 позволяет собрать внешний ASM штатным TASM.

1. Создать модель трёх статусов, отдельно сохранив «нет данных»; проверить переходы и индексы.
2. Проверить подсчёт тревог на реальном ASM: массивы разной длины, null, отрицательный размер.
3. Встроить географию geoBoundaries, сохранить исходный GeoJSON и атрибуцию ODbL.
4. Реализовать VCL-форму с картой, выбором региона, легендой и ручным демосценарием.
5. Собрать EXE и проект IDE, проверить окно и основные действия.
6. Описать запуск и границы первой версии; живой API оставить следующим этапом.

Рутинные технические решения приняты исполнителем. Доступ к живому API и его поставщик пользователем не заданы.
Демонстрационные данные никогда не выдаются за актуальные оповещения.
