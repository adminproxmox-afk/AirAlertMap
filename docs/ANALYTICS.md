# Локальная история и аналитика

Приложение записывает наблюдения в `%LOCALAPPDATA%\AirAlertMap\history-YYYY-MM.jsonl`.
Запись содержит UTC-время Unix, поставщика, доступность данных и 27 состояний
в порядке `data/regions.json`. `N` — нет активной тревоги, `R` — полная,
`P` — частичная, `Y` — предварительная угроза, `?` — нет данных.
Демоданные не включаются в историю. Старт, закрытие и потеря связи создают
границу недоступности. API-ключи и заголовки запросов не записываются.

Новые строки имеют `version:2` и сохраняют прежнее поле `levels` с 27
состояниями. Для доступного ответа UkraineAlarm с подробными территориями
дополнительно записываются `catalog` (16 строчных шестнадцатеричных цифр)
и `territoryLevels` — строка состояний в порядке указанного каталога.
Файл `catalog-<digest>.json` хранится рядом с историей и содержит
`{version:1, provider:"ukrainealarm", territories:[{id,name,parent,type,oblast}]}`.
`id` и `parent` — строки числовых идентификаторов поставщика; пустой `parent`
обозначает отсутствие родителя. `oblast` — индекс 0–26, либо −1, если область
не определена. Имена не используются как ключ: одинаково названные районы
и громады имеют независимую историю по ID. Метаданные отчёта берутся из
последнего проверенного каталога, на который ссылается сохранённая строка,
в том числе при смене имени или порядка территорий.

Python проверяет FNV-1a64 точных UTF-8 байтов каталога, уникальность ID,
типы и размеры полей. Имя файла строится только из проверенного digest;
произвольные пути из истории не открываются. Ограничения: строка истории
до 2 МиБ, каталог до 16 МиБ и 20 000 территорий, имя до 512 символов,
тип до 32 символов, ID до 10 ASCII-цифр. Повреждённая строка учитывается
в `rejected`. Неверный или отсутствующий каталог/набор состояний сохраняет
валидные областные данные, но не подтверждает состояние отдельной территории.

Нажмите «Історія та статистика», чтобы создать отчёт для накопленной истории.
Можно также запустить анализ вручную из папки проекта:

```powershell
python analytics/analyze.py --history "$env:LOCALAPPDATA\AirAlertMap" --output "$env:LOCALAPPDATA\AirAlertMap\reports" --region UA-63
```

Для района, громады или другой территории добавьте числовой ID UkraineAlarm:

```powershell
python analytics/analyze.py --history "$env:LOCALAPPDATA\AirAlertMap" --output "$env:LOCALAPPDATA\AirAlertMap\reports" --territory 101 --since 1793923200
```

`101` здесь — пример ID; используйте ID выбранной территории. `--since`
принимает UTC Unix timestamp, обрезает начало периода и сохраняет предыдущее
наблюдение как исходную точку. `--region` по-прежнему выделяет строку области.
Без `--territory` или с пустым значением создаётся прежний областной отчёт.

Рядом сохраняются `history.html`, `history.csv`, `history.json`. В JSON/CSV
длительности указаны в секундах. HTML выделяет выбранную область. Python
использует только стандартную библиотеку и не обращается к API.
Приложение ищет установленный Python через регистрацию Windows
[PEP 514](https://peps.python.org/pep-0514/) и через `PATH`.

При выборе территории HTML и JSON дополнительно содержат её итоговые
длительности, число начал, суточные итоги и последние 200 подтверждённых
изменений состояния. `history.csv` сохраняет прежний формат 27 областей.
Дополнительные CSV: `territory.csv` — выбранная территория,
`territory-daily.csv` — дни UTC, `territory-events.csv` — изменения состояния.
Все CSV используют UTF-8 с BOM; каждый файл заменяется атомарно.
Повторный отчёт с неизвестным ID заменяет предыдущую строку территории
нулевыми итогами и метаданными `name=ID`, `type=Unknown`, `oblast=-1`.
Без выбранной территории дополнительные CSV содержат только заголовки.

Python API остаётся совместимым: `analyze(paths, since=None, territory=None)`.
JSON сохраняет `rows`, `observations`, `rejected`, `first`, `last`,
`window_seconds`, а также добавляет `territory`: `null` либо объект
`{id,name,type,oblast,red,partial,threat,clear,unknown,starts,daily,events}`.
Каждая строка `daily` содержит `day` (`YYYY-MM-DD` UTC) и шесть итоговых полей;
их суммы совпадают с итогами территории. `events` содержит
`{at,previous,level}` с Unix-временем UTC и кодами `N/R/P/Y`.

Время считается между наблюдениями, максимум 90 секунд на один подтверждённый
ответ. После последнего наблюдения время не достраивается. При смене источника
интервал считается неизвестным. Частичные тревоги и предварительные угрозы
считаются отдельно; переходом считается замеченная смена `N` на `R/P/Y` между
соседними доступными ответами одного источника с интервалом не более 90 секунд.
Начальный активный статус не считается новым началом тревоги.

Для отдельной территории записи версии 1, недоступные ответы, отсутствующий
ID/каталог и неподходящий поставщик означают неизвестный статус. Последний
валидный статус действует до следующей границы наблюдения, максимум 90 секунд;
дальнейшая часть разрыва неизвестна. При смене поставщика неизвестен весь
интервал. Дубликаты UTC-времени сохраняют исходный порядок, не создают событий
с нулевой длительностью и не склеивают границы недоступности. События
требуют двух соседних доступных, известных состояний одного поставщика
с положительным интервалом не более 90 секунд. Они включают все изменения
`N/R/P/Y`; поле `starts` отдельно считает только `N → R/P/Y`.
Интервалы делятся в полночь UTC, а начало относится к UTC-дню события.
Никакое время не добавляется после последнего наблюдения, в том числе
при единственной записи или периоде, начинающемся позже всей истории.

История начинается с этой версии программы. Для истории за прошлые месяцы
потребуется отдельный архив источника — приложение не восстанавливает её задним числом.

## Веб-карта

Встроенный браузер открывает локальные файлы `web/`. C++ передаёт только
публичные уровни тревог, время подтверждения, поставщика, метаданные территорий
и выбор пользователя. Обратные команды выбора, истории и настроек проверяются
нативным приложением; источник сообщения проверяется. Переходы на другие
страницы и новые окна блокируются.
Внешние сетевые подключения самой страницы запрещены CSP.

Интеграция следует документации [локальных файлов WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/working-with-local-content)
и событию [TEdgeBrowser.OnNavigationCompleted](https://docwiki.embarcadero.com/Libraries/Sydney/en/Vcl.Edge.TEdgeBrowser.OnNavigationCompleted).
