# Локальная история и аналитика

Приложение записывает наблюдения в `%LOCALAPPDATA%\AirAlertMap\history-YYYY-MM.jsonl`.
Запись содержит UTC-время Unix, поставщика, доступность данных и 27 состояний
в порядке `data/regions.json`. `N` — нет активной тревоги, `R` — полная,
`P` — частичная, `Y` — предварительная угроза, `?` — нет данных.
Демоданные не включаются в историю. Старт, закрытие и потеря связи создают
границу недоступности. API-ключи и заголовки запросов не записываются.

Нажмите «Історія та статистика», чтобы создать отчёт для накопленной истории.
Можно также запустить анализ вручную из папки проекта:

```powershell
python analytics/analyze.py --history "$env:LOCALAPPDATA\AirAlertMap" --output "$env:LOCALAPPDATA\AirAlertMap\reports" --region UA-63
```

Рядом сохраняются `history.html`, `history.csv`, `history.json`. В JSON/CSV
длительности указаны в секундах. HTML выделяет выбранную область. Python
использует только стандартную библиотеку и не обращается к API.
Приложение ищет установленный Python через регистрацию Windows
[PEP 514](https://peps.python.org/pep-0514/) и через `PATH`.

Время считается между наблюдениями, максимум 90 секунд на один подтверждённый
ответ. После последнего наблюдения время не достраивается. При смене источника
интервал считается неизвестным. Частичные тревоги и предварительные угрозы
считаются отдельно; переходом считается замеченная смена `N` на `R/P/Y` между
соседними доступными ответами одного источника с интервалом не более 90 секунд.
Начальный активный статус не считается новым началом тревоги.

История начинается с этой версии программы. Для истории за прошлые месяцы
потребуется отдельный архив источника — приложение не восстанавливает её задним числом.

## Веб-карта

Встроенный браузер открывает локальные файлы `web/`. C++ передаёт только
публичные уровни тревог, время подтверждения, поставщика и выбранную область.
Обратное сообщение содержит только индекс выбранного региона; источник
сообщения проверяется. Переходы на другие страницы и новые окна блокируются.
Внешние сетевые подключения самой страницы запрещены CSP.

Интеграция следует документации [локальных файлов WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/working-with-local-content)
и событию [TEdgeBrowser.OnNavigationCompleted](https://docwiki.embarcadero.com/Libraries/Sydney/en/Vcl.Edge.TEdgeBrowser.OnNavigationCompleted).
