# Подключение API

Приложение поддерживает два независимых сервиса:

| Где выдан ключ | Что выбрать в настройках | Адрес API |
| --- | --- | --- |
| UkraineAlarm / Stfalcon | UkraineAlarm / Stfalcon | `api.ukrainealarm.com` |
| alerts.in.ua | alerts.in.ua | `api.alerts.in.ua` |

## Подключение

1. Запустите `start.cmd`.
2. Нажмите «Налаштувати API-токен».
3. Выберите сервис, который выдал ключ, в выпадающем списке.
4. Введите ключ и нажмите «Застосувати».
5. Оставьте включённым «Актуальні дані (API)».

Ключ UkraineAlarm не подходит для alerts.in.ua, и наоборот. Приложение не пытается
проверять ключ на другом сервисе автоматически. Для UkraineAlarm используется
заголовок `Authorization: <ключ>`, для alerts.in.ua — `Authorization: Bearer <токен>`.

Ключ вместе с выбранным API по умолчанию сохраняется в Диспетчере учётных данных
Windows для текущего пользователя. При следующем запуске приложение загружает
эту запись автоматически. Ключ не записывается в папку проекта или в текстовый файл.

Флажок «Зберігати ключ на цьому комп’ютері» включён по умолчанию. Если снять его
и нажать «Застосувати», сохранённая запись удаляется, а введённый ключ используется
только до закрытия программы.

Если сохранённой записи нет, используются переменные окружения
`UKRAINEALARM_API_KEY` или `ALERTS_IN_UA_TOKEN`; при наличии обеих выбирается UkraineAlarm.

## Как обновляются данные

Запрос выполняется в отдельном потоке. Интервал обновления — 60 секунд после
завершения предыдущего запроса. Ручное обновление соблюдает тот же интервал.
При ошибке связи или через 90 секунд без подтверждённого ответа карта показывает
«нет данных». Время предыдущего успешного ответа остаётся видимым.

UkraineAlarm: при подключении загружается дерево регионов `GET /api/v3/regions`,
затем, после интервала в 60 секунд, активные тревоги `GET /api/v3/alerts`.
Справочник сохраняется в памяти сеанса: последующие обновления запрашивают только статусы.
Поэтому первое подключение может занять около минуты после загрузки справочника.
Районы и громады связываются с областями по идентификаторам из дерева регионов;
Киев и Киевская область учитываются отдельно. Воздушные тревоги определяются по типу `AIR`.
В покрываемом справочником регионе отсутствие активной тревоги даёт зелёный статус.
Серый означает отсутствие покрытия или неподтверждённые данные.
Если API сообщает неизвестный идентификатор тревоги, справочник загружается заново
при следующей попытке вместо отображения неверного зелёного статуса.

Красный — тревога на всю область. Жёлтый — частичная тревога района/громады
или предварительная угроза. При одновременной полной и частичной тревоге приоритет
имеет красный статус. Значение жёлтого на других картах может отличаться.

alerts.in.ua: `GET /v2/iot/active_air_raid_alerts_by_oblast.json`.
Поддерживаются коды `R`, `Y`, `P`, `N`. Предварительная угроза и частичная тревога
уточняются в карточке региона.

## Ошибки доступа

- **401**: выбранный сервис не принял ключ. Сначала проверьте поставщика в настройках.
- **403**: доступ запрещён. Причина может быть в правах ключа или ограничениях IP;
  это не обязательно означает неправильный ключ.
- **429**: превышен лимит запросов; приложение откладывает следующую попытку.

После 401/403 автозапросы приостанавливаются до повторного применения настроек.
Ключи не сохраняются в исходниках и журналах. HTTPS-сертификаты проверяет Windows,
перенаправления запросов отключены.

Деморежим включается снятием флажка API. Он использует вымышленные статусы и не
запускает новые запросы. При возвращении в API демоданные очищаются.
