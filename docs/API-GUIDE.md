# Подключение актуальных данных

Поставщик: **alerts.in.ua**, endpoint:
`https://api.alerts.in.ua/v2/iot/active_air_raid_alerts_by_oblast.json`.
Документация и получение личного токена: https://devs.alerts.in.ua/

## Как включить

1. Запустите `E:\app\AirAlertMap\start.cmd`.
2. Оставьте включённым флажок «Актуальні дані (API)».
3. Нажмите «Налаштувати API-токен», введите свой токен и примените.
4. После успешного ответа появятся статусы и время «Останній успіх».

Токен хранится только в памяти до закрытия приложения; поле ввода скрыто.
Он не сохраняется в настройках, исходниках или журналах.
Альтернатива: задайте `ALERTS_IN_UA_TOKEN` в окружении процесса перед запуском.
Уже запущенную программу после изменения окружения необходимо перезапустить.
Токен передаётся в Bearer-заголовке по HTTPS только на api.alerts.in.ua.
Перенаправления отключены, сертификаты проверяет Windows.

## Обновления и статусы

- Автообновление каждые 60 секунд после завершения предыдущего запроса.
- Ручная кнопка соблюдает ту же задержку; параллельных запросов нет.
- Все 27 позиций ответа сопоставлены с геометрией отдельной таблицей.
- `R`: тревога, `Y`: предварительная угроза, `P`: частичная тревога.
  Все три входят в активный счётчик; подробность видна в карточке и подсказке.
- `N`: поставщик не сообщает активной тревоги. Это не гарантия безопасности.
- Ошибки сети/HTTP/JSON переводят карту в «нет данных».
- Без подтверждённого ответа 90 секунд данные становятся неизвестными.
- Ответ с HTTP Age от 90 секунд не применяется.
- `401`/`403` приостанавливают запросы до повторного задания токена.
- `429`/`503` учитывают Retry-After: минимум 60 секунд, максимум один час.
- Время «Останній успіх» — локальное время получения ответа, а не объявления тревоги.
  При ошибке время предыдущего успеха остаётся видимым, а статусы становятся неизвестными.

Без токена начальное состояние — 27 регионов без данных.
Успешный авторизованный ответ требует действующего токена; без него не проверялся.
Для решений о безопасности пользуйтесь официальными оповещениями.
Поставщик может иметь собственные задержки обновления.

## Деморежим

Снимите флажок API. Появятся кнопки смены демостатуса и сброса сценария.
Данные вымышлены: 6 активных регионов, 18 без тревоги, 3 без данных.
Новые сетевые запросы не запускаются; поздний ответ старого запроса не изменяет демокарту.
При возврате в API демостатусы очищаются до нового успешного ответа.
Ограничение частоты запросов сохраняется при смене режима и токена.

## Технические детали и проверка

`AlertFeed` — строгий разбор JSON, таблица регионов, срок актуальности.
`AlertsHttp` — WinHTTP с HTTPS, ограничением тела 4 КБ и обработкой HTTP-ошибок.
Тайм-ауты: DNS 3 с; соединение, отправка и чтение по 5 с; цикл чтения ограничен по времени.
Сетевой TThread не вызывает VCL и Synchronize. UI проверяет завершение потока,
после чего применяет цельный снимок. При смене режима/токена поколение запроса
меняется; устаревший результат не применяется. При закрытии приложения текущий
запрос завершается по установленным тайм-аутам.

`build.ps1 -TestsOnly` выполняет 134 проверки без сети.
`build\HttpTests.exe --smoke` дополнительно проверяет настоящий HTTPS-запрос
с заведомо неверным тестовым токеном и обработку отказа в доступе.
Он не читает и не использует личный токен.

Для публичного распространения поставщик требует серверный прокси.
Эта версия предназначена для личного запуска с собственным токеном.
Требования и ограничения: https://devs.alerts.in.ua/
