# Единое окно AirAlertMap

Пользователь выбрал HTML/CSS/JS для всего интерфейса и C++Builder + ASM
для основной логики. Главное окно сразу содержит WebView2; отдельное окно
веб-карты и рисованная VCL-карта больше не нужны.

Навигация: «Мапа», «Історія», «Налаштування». Сохраняются украинские тексты,
цвета состояний и локальные границы. Тёмный синий фон #101820, панели #17232d,
линии #33434f, текст #ecf2f5, бирюзовый акцент #64c5b6; красный и жёлтый
используются для тревог. Segoe UI — основной текст, Consolas — время и числа.
Карта получает большую часть окна, счётчики компактные. На узком окне панели
перестраиваются, все действия доступны с клавиатуры.

C++ отправляет JSON-состояние через PostWebMessageAsJson: статусы, результат
ASM-подсчёта, выбранный регион, состояние подключения, обратный отсчёт,
наличие/сохранение ключа и результат Python. Сам ключ назад не отправляется.
Команды страницы имеют версию, известный тип и строго проверяемые поля.
Сообщения принимаются только от точного локального URL. Чужая навигация,
новые окна и внешние запросы страницы блокируются.

Настройки: поставщик API, ввод нового ключа, сохранение в Windows Credentials,
выбор области и переключение деморежима. Пустой ключ сохраняет существующий
только при неизменном поставщике. Удаление ключа требует явного действия
в интерфейсе. Пароль не сохраняется в localStorage и очищается после отправки.
Ошибки отображаются внутри страницы.

История: локальный Python по-прежнему считает статистику. JSON загружается
в тот же интерфейс, с выбором области и периода (сутки/7/30 дней/вся история).
Старые ответы и пробелы наблюдения не считаются отсутствием тревоги.
HTML/CSV/JSON можно экспортировать через стандартный системный диалог файла.
Открытия отдельного браузера для просмотра истории больше нет.

Проверки: C++-тесты протокола (типы, диапазоны, неверные команды, ключи),
Python-тесты ограничения периода, существующие C++/ASM-тесты, браузерная
проверка навигации, формы настроек, ошибок, отсутствия данных и экспорта;
сборка CLI/IDE и запуск настоящего EXE с сохранённым ключом без его чтения.
