# Развитие AirAlertMap

Приложение остаётся на C++Builder VCL + x86 ASM. Пользователь выбрал сначала
ускорение запуска и сохранение выбранной области, затем Python и веб-карту.

## Хранение и запуск

Справочник UkraineAlarm сохраняется в `%LOCALAPPDATA%\AirAlertMap` отдельно
от ключа. При загрузке проверяются версия, срок хранения (24 часа), размер и
схема. Повреждённый, просроченный или записанный с будущей датой справочник
не используется. Новая запись заменяет старую атомарно. При ошибке формата
ответа справочник сбрасывается, чтобы следующий запрос восстановил его.
Выбранная область сохраняется по ISO-коду, а не по позиции в списке.
Следующий допустимый запрос запоминается отдельно для каждого поставщика,
чтобы перезапуск не обходил минутный интервал или Retry-After.
Статусы тревог при старте запрашиваются заново; справочник не является
доказательством отсутствия тревоги. API-ключ остаётся в Windows Credentials.

## История и Python

C++ записывает локальные наблюдения статусов в JSONL с UTC-временем,
поставщиком и признаком доступности. В истории нет ключей или HTTP-заголовков.
Python использует стандартную библиотеку, рассчитывает длительности по
наблюдениям и создаёт HTML/CSV/JSON. Разрывы наблюдения и смена поставщика
не считаются подтверждённым отсутствием тревоги; максимум подтверждения
одного наблюдения — 90 секунд. Это история работы приложения, не официальный
архив и не точные времена начала/окончания тревог.

## Интерактивная карта

Локальная HTML/CSS/JS-страница во встроенном WebView2 использует те же
27 географических регионов. Масштабирование, перемещение, выбор области,
подписи, границы и заливка статусов работают без внешних картографических
сервисов. C++ передаёт только очищенные статусы и выбранную область.
Переходы на внешние страницы блокируются. Обычная VCL-карта остаётся доступной.
Более подробные административные границы требуют отдельного набора геоданных.

## Проверка

Тесты хранения используют отдельный временный каталог, без реального ключа.
Проверяются восстановление, срок годности, повреждения, неверные ISO-коды,
раздельные ограничения API и обработка ошибок диска. Для Python проверяются
разрывы, повторные статусы, смена источника и экранирование HTML. Веб-карта
проверяется на выбор региона, масштабирование и отображение отсутствия данных.
